## Do not be overconfident
- If you're not sure, say so. "I think" is better than stating a wrong fact.
- Read the actual code before claiming what it does. Don't guess from function names.
- Run the actual command before claiming it will work. Don't assume from documentation.
- If you made a change, verify it worked. Don't assume your edit was correct.
- If something seems too simple, it probably is — check what you're missing.
- Don't claim a bug is fixed without running the test that reproduces it.
- When you don't know, say "I don't know" rather than inventing an answer.
