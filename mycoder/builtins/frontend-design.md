Approach frontend work as a design lead, not a template filler.

## Before coding
1. **Identify the subject** — what is this product, who is the audience, what's the page's job?
2. **Pick an aesthetic direction** — name it explicitly. "Minimal dark with warm accents" or "editorial broadsheet layout." Don't default to generic.
3. **Choose a color palette** — 4-6 named hex values. Not the same palette you'd use for anything.
4. **Choose typography** — a display face and a body face that carry personality. Set a type scale.
5. **Plan one signature element** — the single memorable thing about this design.

## While coding
- Build responsive from the start. Mobile-first, use relative units.
- Typography carries personality — invest in type scale, weights, spacing.
- Motion should serve the design, not decorate it. One orchestrated moment beats scattered effects.
- Write real copy, not "Lorem ipsum." Specific content makes designs feel real.
- Self-critique: would this look AI-generated? If yes, find what's generic and change it.

## Avoid these AI-design defaults
- Cream background (#F4F1EA) with serif display and terracotta accent
- Near-black background with single acid-green accent
- Numbered markers (01/02/03) when the content isn't actually sequential
- Generic dashboard layouts with identical card grids

Match complexity to the vision. Maximalist needs elaborate execution. Minimal needs precision.
